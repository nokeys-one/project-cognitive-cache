# Acknowledgments and project lineage

Project Cognitive Cache was designed after studying [learn-by-building](https://github.com/chaojiwudibing/learn-by-building), an open-source Agent Skill created and maintained by [chaojiwudibing](https://github.com/chaojiwudibing).

The original project established the learning-oriented context: an AI should help a user understand a real project while building it. This repository addresses a distinct follow-up problem—repeated repository reads and context cost across sessions—through a persistent local summary, deterministic fingerprints, incremental invalidation, and hard loading budgets.

This repository is an independent project. It is not an official release, fork, or endorsement of `learn-by-building`, and it does not claim authorship of the original project's work.
